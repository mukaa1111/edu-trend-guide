# 텔레그램 알림 설정 (TELEGRAM)

화요일 아침 자동 갱신이 끝나면 텔레그램으로 "2주 안에 마감되는 것 + 새로 들어온 것 + 페이지 주소"를 보내줘요.

**교육 수첩은 전용 봇을 따로 써요.** '주말 뭐하지'와 같은 봇을 쓰면, 교육 수첩 알림에 답장했을 때 주말 뭐하지의 저녁 루틴이 그 답장을 행사 요청으로 읽기 때문이에요. 봇이 다르면 대화방도 따로 생겨서 알림이 섞이지 않아요.

## 한 번만 하면 되는 준비 (약 3분, 직접 해야 함)

### 1. 교육 수첩용 봇 만들기 (텔레그램 앱에서)
1. 텔레그램 검색창에서 **BotFather** 를 찾아 대화 열기 (파란 체크 표시가 있는 공식 계정)
2. `/newbot` 입력
3. 봇 이름: 예) `교육 수첩 알리미`
4. 봇 아이디(영문, 끝이 `bot`): 예) `edu_sucheop_bot` (이미 있다고 하면 숫자 붙이기)
5. BotFather가 **토큰**을 줘요. `123456789:AAH...` 같은 긴 글자예요.
   **토큰은 비밀번호예요. 채팅에 붙여넣지 말고 3번에서 직접 입력하세요.**

### 2. 새 봇과 대화 시작해 두기
- 방금 만든 봇을 검색해서 열고 **시작(Start)** 을 한 번 눌러요. 이걸 안 하면 봇이 먼저 메시지를 못 보내요.

### 3. 클라우드 환경에 값 넣기
1. https://claude.ai/code → 아래쪽 **Default**(환경) 설정 열기
2. **환경 변수**에 한 줄 추가:
   - 이름 `EDU_TELEGRAM_BOT_TOKEN` / 값: 1번에서 받은 토큰
3. 저장

chat id는 새로 넣을 필요가 없어요. 받는 사람이 같아서 이미 있는 `TELEGRAM_CHAT_ID`를 그대로 써요.
(다른 사람이나 단체방으로 보내고 싶으면 `EDU_TELEGRAM_CHAT_ID`를 따로 넣으면 그게 먼저 쓰여요.)

## 환경 변수 정리 (세 서비스 합쳐서)
| 이름 | 쓰는 서비스 | 비고 |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | 주말 뭐하지, 트렌드 레이더 | 기존 봇 |
| `TELEGRAM_CHAT_ID` | 세 서비스 모두 | 내 chat id |
| `EDU_TELEGRAM_BOT_TOKEN` | 교육 수첩 | **새로 만든 전용 봇** |
| (그 밖에 다른 서비스가 쓰는 변수) | 각 서비스 문서 참고 | |

`EDU_TELEGRAM_BOT_TOKEN`을 안 넣으면 기존 봇으로 보내요. 그때는 교육 수첩 알림에 답장하지 마세요.

## 동작 방식
- 루틴이 끝날 때 `bash scripts/telegram.sh "메시지"` 를 실행해요.
- 환경 변수가 없으면 조용히 건너뛰어요 (갱신 자체는 영향 없음).
- **답장은 읽지 않아요.** 고칠 게 있으면 Claude에게 직접 말해 주세요.


## 계정 옮길 때
- 봇과 토큰은 **내 텔레그램 계정** 것이라 그대로 써요.
- 새 Claude 계정의 클라우드 환경에 3번(환경 변수)만 다시 넣으면 돼요.
