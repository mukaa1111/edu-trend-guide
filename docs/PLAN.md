# 만들기 순서 (체크리스트)

각 단계는 한 번의 대화로 끝낼 수 있는 크기예요. 위에서부터 차례로.

## 1단계. 뼈대 만들기
- [x] 폴더 구조 만들기: `index.html`, `data/items.js`, `docs/`
- [x] 정보 한 건의 양식 정하기 (제목·요약·지역·학년·시기·과목·종류·출처·수집일·신뢰도)
- [x] 샘플 항목 5개를 손으로 넣어서 양식이 쓸만한지 확인 (내가 보고 양식 OK인지 확인)

## 2단계. 화면 만들기
- [x] 카드 목록이 보이는 기본 페이지
- [x] 학년·과목·종류·지역 필터 버튼
- [x] 키워드 검색창
- [x] "시기별 로드맵" 탭 (학년·시기 순으로 정렬해서 보기)
- [x] 핸드폰 화면에서 깨지지 않는지 확인 (브라우저에서 확인함)

## 3단계. 1차 정보 수집 (공개 웹)
- [ ] 둔산: 주요 학원·대회·설명회 정보 조사
- [ ] 대치·목동: 참고용 로드맵·트렌드 조사
- [ ] 과목별 학습지·교재 단계 (수학/영어 우선, 그 다음 국어·과학·사회)
- [ ] 초등 대상 주요 대회 일정·접수 시기
- [ ] 경험활동 (독서·체험·캠프 등) 추천 시기
- [ ] 모든 항목에 출처 링크 + 수집일 붙이기, 60건 이상 채우기
- [ ] 내용 훑어보고 틀리거나 오래된 것 걸러내기 (내가 확인)

## 4단계. 네이버 카페 정리
- [ ] 앱 브라우저에서 네이버 로그인 (내가 직접)
- [ ] 카페 주소·게시판 이름 알려주기
- [ ] 게시판별 최근 글 요약 → 항목으로 추가 (원글 링크 포함)

## 5단계. 인터넷에 올리기

- [ ] 저장소 `edu-trend-guide` 만들고 파일 올리기, GitHub Pages 켜기 → https://mukaa1111.github.io/edu-trend-guide/
- [ ] 핸드폰에서 주소 열어보기, 가족에게 링크 보내기

## 6단계. 운영
