# 자동 갱신 루틴 (ROUTINE)

매주 **화요일** 아침 7시에 클라우드에서 돌아가는 "교육 수첩 자동 갱신" 예약의 설정이에요.
**다른 Claude 계정으로 옮길 때** 이 문서를 보여주고 "docs/ROUTINE.md대로 루틴 만들어줘"라고 하면 돼요.

## 하는 일
1. 마감이 지난 대회·설명회의 **다음 회차 일정**을 찾아 날짜를 고쳐요.
2. 둔산 학원 설명회·개강, 초등 대회 접수, 대전 과학·체험 프로그램 중 **새로 열린 것**을 찾아 추가해요.
3. 바뀐 내용이 있으면 "핵심만" 요약(`data/guides.js`)도 맞춰 고쳐요.
4. GitHub에 올리고, 텔레그램으로 **2주 안에 마감되는 것**과 바뀐 내용을 보내요.

매달 첫 화요일에는 수집한 지 6개월 넘은 자료도 다시 확인해요.

화요일인 이유: 월요일에는 다른 서비스 루틴이 이미 4번 돌아요(트렌드 레이더 아침·저녁, 주말 뭐하지 수집·회신). 요금제의 하루 실행 한도에 걸리지 않게 하루 비켜 뒀어요.

## 루틴에 넣는 짧은 글 (루틴을 새로 만들 때 이걸 넣음)

> 너는 '우리 아이 교육 수첩'(edu-trend-guide) 저장소의 자료 갱신 에이전트다. 대전 둔산에 사는 학부모가 초등 2학년 자녀의 교육 정보를 모아 보는 정적 웹페이지이고, 모든 글은 한국어로 쓴다.
>
> 이 저장소의 `docs/ROUTINE.md`를 열어 맨 아래 "## 루틴 지시문" 제목 아래 코드 블록 안의 지시문을 읽고, 그 지시문을 처음부터 끝까지 그대로 수행하라. 그 코드 블록이 이번 실행의 전체 지시다. ROUTINE.md의 다른 부분은 참고만 하고 고치지 않는다.
>
> 꼭 지킬 것: `data/items.js`(약 350KB)를 통째로 열지 말고 `scripts/edit.js`와 `scripts/check.js`만 쓴다. 올릴 파일은 `data/items.js`, `data/guides.js`, `docs/COLLECT.md` 세 개뿐이고 `git add -A`를 쓰지 않는다. `main`에 바로 커밋·푸시하고 PR은 만들지 않는다. 마지막에 `bash scripts/telegram.sh "<메시지>"`를 한 번 실행한다(환경 변수가 없어 건너뛰어도 오류가 아님). 확인하지 못한 날짜나 사실을 지어내지 않는다.

## 할 일
0. **`data/items.js`를 통째로 읽지 않는다** (350KB라 한 번 읽으면 실행이 무거워진다). 형식은 `head -20 data/items.js`로만 보고, 항목은 아래 도구로 한 건씩 다룬다.
   - 찾기: `node scripts/edit.js find 단어 [단어…]` → "id | 마감 | 제목"
   - 한 건 보기: `node scripts/edit.js get <id>`
   - 일부 필드만 고치기: 바꿀 필드만 담은 JSON 파일을 만들고 `node scripts/edit.js set <id> 파일.json` (값이 null이면 그 필드를 지움)
   - 새 항목 추가·통째 교체: 항목 JSON(1건 또는 배열) 파일을 만들고 `node scripts/edit.js upsert 파일.json`
   - 삭제: `node scripts/edit.js delete <id> [id…]`
   - 임시 JSON 파일은 저장소 밖 임시 폴더(`$TMPDIR` 또는 `/tmp`)에 만든다. 저장소에 넣지 않는다.
1. `TZ=Asia/Seoul date +%Y-%m-%d` 로 오늘 날짜를 확인한다.
2. **지난 마감 갱신**: `node scripts/check.js past` 로 마감이 지난 항목을 본다 (마감일이 오늘인 것은 아직 지난 것이 아니다). 항목마다 `edit.js get`으로 `url`을 확인해 그 공식 페이지를 WebFetch로 먼저 열고, 아래 순서로 처리한다.
   ① 적혀 있던 이번 회차 날짜가 틀렸으면 먼저 바로잡는다. 바로잡은 마감이 아직 안 지났으면 거기서 끝.
   ② 해마다·분기마다 반복되는 것(대회, 인증시험, 학원 분기 개강, 영재원 선발, 과학관 프로그램, 고입 원서)은 다음 회차 일정으로 `deadline`, `timing`, `summary`, `url`을 고친다.
   ③ 다음 회차가 아직 공지되지 않았으면 `deadline`을 null로 지우고 `note`에 "다음 일정 미공지(○월 확인)"라고 적는다.
   ④ 1회성 설명회·행사는 삭제한다. 요약에 체험수업 같은 뒷일정이 남아 있어도 삭제하고, 그 뒷일정이 중요하면 새 항목으로 따로 만든다.
   고친 항목은 모두 `collected`를 오늘로 바꾼다.
3. **새 소식 찾기**: WebSearch와 WebFetch로 아래를 찾아 새 항목으로 추가한다. 추가하기 전에 `edit.js find`로 같은 내용이 있는지 확인하고, 있으면 `set`으로 갱신만 한다.
   - 둔산 학원 설명회·입학시험·개강 (CMS, 에이프릴, 정상, 와이즈만, 시매쓰, 깊은생각 등. 크레버스 공식 페이지, 런즈·프롬피 학원 소식)

   - 제도 변화: 지역인재·지역의사 전형, 대전 자사고·과학고·영재학교 전형과 경쟁률, 영재원 선발 방식 (바뀐 게 있을 때만)
   **조사 방법**: 먼저 `docs/SOURCES.md`의 "매주 볼 곳" 표에 있는 주소를 WebFetch로 차례로 연다 (실제로 열리는 것을 확인한 공식 게시판 주소다). WebSearch는 한국어 결과가 부정확하니 보조로만 쓴다. 공식 사이트와 일정 페이지를 WebFetch로 직접 여는 것을 우선한다 (예: hme.chunjae.co.kr/hme/hme_info/hme_schedule.asp, kma-e.com/eval/schedule.asp, kmath.co.kr, toeflyss.or.kr/test/testSchedule, creverse.com/mt/daejeondunsan, creverse.com/april/dunsan, science.go.kr, edurang.net/dmcc, ged.kedi.re.kr). 글자가 깨지거나 일정이 안 보이는 사이트는 넘어간다.
