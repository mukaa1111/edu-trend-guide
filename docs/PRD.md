# 우리 아이 교육 정보 모음 (가칭) — PRD

작성일: 2026-11-09

## 한 줄 요약
둔산(1순위)·대치·목동의 초등 교육 트렌드, 대회, 학원, 학습지, 경험활동 정보를
학년·과목·종류별로 모아두고, 궁금할 때 핸드폰이나 PC에서 바로 찾아보는 가족용 웹페이지.

## 누가 쓰나
- **주 사용자**: 나 (초2 자녀 둘, 개발 비전공)
- **부 사용자**: 가족·지인 몇 명 (링크 받아서 보기만 함)
- 로그인 없음. 링크를 아는 사람만 봄.

## 다루는 범위
- 학년: **초2 ~ 초6 중심**. 중1~중3(선행·특목·고입)은 참고 수준으로 일부.
- 지역: **둔산 1순위**, 대치·목동은 비교·참고용.
- 과목: 국어, 수학, 영어, 과학, 사회, 예체능/기타
- 종류: 대회 / 학원 / 학습지·교재 / 경험활동(체험·독서·캠프 등) / 트렌드·시기별 로드맵

## 핵심 기능 (이번 버전)
1. **정보 카드 목록** — 한 건당: 제목, 핵심 요약, 지역, 학년, 시기(예: 3학년 겨울방학), 과목, 종류, 출처 링크, 수집일, 신뢰도 메모
2. **필터 + 검색** — 학년·과목·종류·지역을 골라서 보기, 키워드 검색 (예: "경시대회", "원서")
3. **시기별 로드맵 보기** — "초3 겨울엔 뭘 해야 하나" 식으로 학년·시기 순서대로 쭉 보기
4. **1차 자동 수집** — Claude가 최근·신뢰도 있는 공개 웹 자료를 조사해서 처음 내용을 채움. 이후 내가 로그인한 네이버 카페 게시판도 요약·정리해서 추가
5. **말로 추가하기** — "이 내용 추가해줘"라고 Claude에게 말하면 데이터 파일에 넣어주고 페이지에 반영됨

## 이번엔 안 할 것
- 회원가입·로그인, 사용자별 설정
- 웹페이지 안에서 직접 글 쓰는 입력 폼 (추가는 Claude에게 말로)
- 월 1회 자동 정기 업데이트 (몇 주 써본 뒤 필요하면 켬)
- 댓글, 좋아요, 알림 같은 커뮤니티 기능
- 학원 글 원문 통째로 복사 (요약 + 원글 링크만)
- 유료 서비스·앱스토어 앱

## 기술 선택 (가장 단순한 방식)
- **데이터**: `data/items.js` 파일 하나 — 서버·DB 없이 파일만 고치면 돼서 고장 날 데가 없음. (weekend-events와 같은 방식)
- **화면**: HTML 파일 하나(`index.html`)에 필터·검색 포함 — 설치·빌드 없이 더블클릭해도 열림.
- **호스팅**: GitHub Pages (무료, 계정 mukaa1111) — 파일 올리면 바로 인터넷 주소가 생겨 핸드폰에서 열림.
- **정보 추가**: Claude가 `items.js`에 항목 추가 → GitHub에 올리면 반영 — 입력 화면을 만들 필요가 없음.

## 성공 기준
- 핸드폰에서 링크 열고 10초 안에 "초3 수학 학습지" 같은 걸 찾을 수 있다.
- 1차 수집 후 항목 60건 이상, 모든 항목에 출처 링크와 수집일이 있다.
