# 우리 아이 교육 정보 — 사용 안내

둔산(1순위)·대치·목동의 초등 교육 트렌드, 대회, 학원, 학습지, 경험활동 정보를 학년·과목·종류별로 모아 보는 가족용 페이지예요.

## 여는 법
- **폰이나 어디서든**: https://mukaa1111.github.io/edu-trend-guide/
- **PC에서 파일로**: 이 폴더의 `index.html`을 더블클릭해도 같은 화면이 떠요.
- 파일을 고친 뒤 폰 주소에도 반영하려면 "GitHub에 올려줘"라고 말하면 돼요.

## 파일 설명
| 파일 | 뭐 하는 파일인가 |
|---|---|
| `index.html` | 화면. 건드릴 일 거의 없어요. |
| `data/items.js` | 정보 목록. Claude가 수집해서 채우고, 직접 고쳐도 돼요. 맨 위 주석에 항목 양식 설명이 있어요. |
| `docs/PRD.md` | 무엇을 만드는지 정리한 기획서 |
| `docs/PLAN.md` | 만드는 순서 체크리스트 |

## 자주 쓰는 말 (Claude에게)
- "이 내용 추가해줘: (내용)" → `data/items.js`에 항목 추가
- "둔산 수학학원 최신 정보 찾아서 넣어줘" → 조사 후 항목 추가
- "GitHub에 올려줘" → 폰 주소에 반영
